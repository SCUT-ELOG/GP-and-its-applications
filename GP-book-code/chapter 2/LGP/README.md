# 线性遗传编程(LGP)算法实现

本项目提供了一个完整的线性遗传编程(LGP)算法的Python实现，主要用于符号回归问题。

## 算法特点

- **线性编码**: 使用类似汇编语言的线性指令序列表示程序
- **稳态演化**: 采用Steady-State EA演化策略
- **多种遗传操作**: 锦标赛选择、双点交叉、随机变异
- **灵活配置**: 可自定义函数集、寄存器数量和演化参数

## 文件结构

- `lgp.py`: LGP算法核心实现
- `example_usage.py`: 使用示例和演示
- `requirements.txt`: 项目依赖
- `README.md`: 项目说明文档
